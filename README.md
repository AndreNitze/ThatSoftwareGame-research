# ThatSoftwareGame research resources

This repository contains public research metadata, citation information, open educational resources (OER), and other openly published research materials related to **ThatSoftwareGame**, a proprietary serious game for project management education.

## About ThatSoftwareGame

ThatSoftwareGame is a web-based serious game for experiential learning in IT project management. It combines briefing and evaluation phases with a real-time project simulation in which participants make project decisions and experience their consequences.

- Project website: https://thatsoftwaregame.com/
- Research and citation page: https://thatsoftwaregame.com/en/research/
- Research Snapshot DOI: https://doi.org/10.5281/zenodo.21933399
- ORCID: https://orcid.org/0000-0003-0752-917X
- Affiliation: Technische Hochschule Brandenburg (ROR: https://ror.org/04qj3gf68)

## Open educational resources

### Five Questions for Debriefing Simulation Games

A compact, evidence-informed OER for educators and facilitators who use simulation games, business games, board-based simulations, or digital serious games. It adapts the Five Questions model from Jacobson and Ruddy's *Open to Outcome* (2nd ed.) to the debriefing of simulation games and includes two worked examples plus a one-page facilitator cheat sheet.

Sources and build files are available in [`oer/five-questions-debriefing/`](./oer/five-questions-debriefing/).
