# ThatSoftwareGame research metadata

This repository contains public research metadata, methods documentation, and citation information for **ThatSoftwareGame**, a proprietary serious game for project management education.

## About ThatSoftwareGame

ThatSoftwareGame is a web-based serious game for experiential learning in IT project management. It combines briefing and evaluation phases with a real-time project simulation in which participants make project decisions and experience their consequences.

- Project website: https://thatsoftwaregame.com/
- Research and citation page: https://thatsoftwaregame.com/en/research/
- Research Snapshot DOI: https://doi.org/10.5281/zenodo.21933399
- ORCID: https://orcid.org/0000-0003-0752-917X
- Affiliation: Technische Hochschule Brandenburg (ROR: https://ror.org/04qj3gf68)
